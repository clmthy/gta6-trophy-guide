# Leonida Ledger — GTA VI Trophy Guide & Tracker

The best offline guide and tracker for the 55 PlayStation 5 trophies of GTA VI (1 platinum, 2 gold, 6 silver, 46 bronze — all offline, none online). A static web app: open `app/index.html` in a desktop browser and it works with no network at all.

## What it does

- **Checklist of all 55 official trophies** — exact names, descriptions and grades from the official list (Exophase and PSNProfiles, agreeing on every one). Tick one off and it stays ticked, saved in the browser.
- **A full guide for every trophy, in the author's own words, with its sources named beside it** — what to do, where and how, and when it can be missed. Where a method is not public yet on launch day (2026-11-19), the guide says so instead of inventing one. Where two launch-day sources disagree (the shooting-range count, the drone-race count, the stunt count), the guide says so and follows the official description.
- **Filters by kind** (story, missable, collectibles, activities, online) and by grade, plus **search** across names, descriptions and guides.
- **Spoiler setting** — hides story trophies' names and descriptions until earned.
- **Roadmap to the platinum** — three phases (story, side content, cleanup), the 100% completion requirements (100 objectives, 16 Strangers & Freaks missions), difficulty 4/10, about 200 hours, with progress counters per phase.
- **Missables flagged** — no trophy is confirmed missable; the one possible exception (a Chapter 1 kitchen meditation, unconfirmed per Push Square) is flagged clearly.
- **Your notes** on any trophy, saved in the browser, and a **Next up** suggestion.
- **Export and import** of progress as JSON, so it moves between browsers.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or open `app/index.html` directly from any static file server. No build step, no network requests, no accounts.

## Sources

Names, descriptions and grades: the official trophy list on Exophase and on PSNProfiles. How-to: the PowerPyx trophy guide & roadmap, the PowerPyx 100% completion checklist, the PowerPyx shooting-range guide, the PowerPyx drone-race guide, and the Push Square trophy guide. The guides themselves are this app's own words — never copied from any source.
